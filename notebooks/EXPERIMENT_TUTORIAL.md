# Experiment tutorial

`experiment_tutorial.ipynb` connects native path analysis to assignment-aware
outcomes, interval estimates and explicit hypothesis tests. It runs on this
development branch; the new methods are not available in PyPI 5.3.0.

`lumeo_experiment_tutorial.ipynb` adds the frozen Lumeo integration case: four
different conversion questions, sparse/outlier support and UI observation
coverage. Its selected synthetic parent is disclosed; it is not a calibration
benchmark. The five source tables, hashes and data card are in `data/lumeo/`.

## Install this source branch

Use Python 3.10–3.13 and Node.js. From a checkout of the branch:

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install -e . nbclient nbformat nbconvert ipykernel matplotlib
npm ci --prefix js
npm run build --prefix js/viz-core
python scripts/export_metric_schema.py
npm run build --prefix js/widget
```

Open the notebook in that Python environment and run it from `notebooks/`.
`experiment_demo.py` contains the fixed, independent event simulation;
`experiment_helpers.py` formats exported payloads and embeds native widgets;
`experiment_plots.py` draws saved intervals without recalculation.

The first scenario declares 500 units per arm, purchase probabilities .10/.13,
variable repeated orders, silent assigned users and source history before
assignment. The seed is fixed without outcome-based selection. Known population
targets are distinct from realized sample estimates. A/A and repeated simulations
are validation scenarios, not promises that each realized test is significant.

The tutorial demonstrates native graph/step matrix exploration, a shared pattern
outcome, explicit Clopper–Pearson/conservative difference intervals, explicit approximate user-bootstrap mean/ratio estimates,
ordered cumulative/conditional funnels, an exact small ratio counterexample,
and invariance when each person's sessions are duplicated uniformly.

## Run without an interactive frontend

```bash
python examples/experiments/execute_tutorial.py
python examples/experiments/execute_tutorial.py --lumeo
```

This executes with the invoking Python environment and exports an executed
notebook, HTML, figures, native widgets and metadata into `artifacts/experiment_tutorial/`.
Source notebook outputs remain clear. No dataset download or regeneration is
required beyond the fixed synthetic example generated by the helper.

## Validate statistical behavior

```bash
python examples/experiments/validate_methods.py --trials 40 --resamples 999
```

This includes public API event extraction, binary null/effect/rare scenarios,
correlated repeated-order ratios, exact Monte Carlo uncertainty and a repeated-
session invariant. The default is a small smoke check; increase trials for a
more precise assessment. Report availability and coverage separately. A result
from selected teaching data must not serve as a coverage oracle.

This first API supports two independent arms, a fixed common complete outcome
window, supported scalar outcomes and explicit interval/test methods. It does
not supply sequential, paired, cluster-randomized or individual-horizon inference.
See [the experiment guide](../docs/guide/experiments.md) for the complete contract.

The conservative exact difference is not a Fisher-test inversion. Strict
`binary_intervals=None`, `bootstrap=None`, `tests=None` add no inference.
Approximate monetary inference remains sensitive to rare and heavy-tailed outcomes.
